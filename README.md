# Computer Vision Assignments 📷🧠

This repository contains a series of Computer Vision assignments completed as part of an academic course. Topics range from basic image processing to camera projection, geospatial image handling, and feature detection.

## 🛠️ Tools & Libraries

- Python  
- OpenCV  
- NumPy  
- GDAL  
- PyQt5 / Tkinter  
- Matplotlib
- PyTorch
- TensorFlow
- wandb
